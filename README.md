Smart Parking System

A C++ based Smart Parking System developed as a class project using Object-Oriented Programming (OOP) concepts.

Features

- Vehicle entry and exit management
- Parking slot management
- Vehicle information handling
- Parking fee calculation
- Simple and user-friendly console interface

Technologies Used

- C++
- Object-Oriented Programming (OOP)

Project Purpose

This project demonstrates the practical use of C++ programming and OOP concepts to develop a simple parking management system.
